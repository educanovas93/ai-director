# AI Director

An AI-driven director platform for live video production — it watches the available
sources (cameras, screen shares, feeds) and decides what goes on air, when to cut,
and how the scene is composed, so a stream or recording can be produced with little
or no manual switching.

> Status: **skeleton** — the architecture and implementation plan are being defined.
> The authoritative plan will live in [`docs/PLAN.md`](docs/PLAN.md).
